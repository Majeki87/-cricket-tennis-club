# 귀뚜라미 테니스 클럽

개인 연습(컴퓨터 상대)과 실시간 2인 대전을 지원하는 웹게임입니다.

## 포함 기능
- 개인 연습: 키보드/터치 조작, 컴퓨터 상대, 5점 선취
- 실시간 대전: 방 만들기, 6자리 방 코드 공유, 2명 접속
- PC 및 모바일 브라우저 지원
- Node.js + Express + WebSocket

## 로컬 실행
1. Node.js 18 이상 설치: https://nodejs.org/
2. 압축을 푼 폴더에서 터미널/명령 프롬프트 실행
3. 아래 명령 실행

```bash
npm install
npm start
```

4. 브라우저에서 `http://localhost:3000` 접속

같은 와이파이의 다른 기기에서 접속하려면 호스트 PC의 내부 IP를 확인한 뒤 `http://호스트PC_IP:3000`으로 접속하세요. 방화벽에서 TCP 3000 포트를 허용해야 할 수 있습니다.

## 인터넷에 공개 배포하기 (Render 예시)
실시간 대전은 WebSocket 연결을 지원하는 서버에 배포해야 합니다. 정적 호스팅만으로는 실시간 대전이 동작하지 않습니다.

1. 이 프로젝트 폴더를 GitHub 저장소에 업로드합니다.
2. Render에서 **New + → Web Service**를 선택하고 GitHub 저장소를 연결합니다.
3. Runtime은 Node, Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 배포가 끝나면 Render가 제공하는 HTTPS 주소를 직원들에게 공유합니다.
5. 한 명은 **방 만들기**, 다른 직원은 같은 주소에서 **실시간 대전 → 방 코드 입력 → 참가**를 누릅니다.

Render는 플랜/요금 및 무료 서비스 정책이 변경될 수 있습니다. 무료 인스턴스는 일정 시간 비활성 후 잠들 수 있어 첫 접속이 늦어질 수 있습니다. 실시간 대전은 두 브라우저가 같은 배포 서버에 접속해야 합니다.

## 참고
- 현재 버전은 사내 친선 게임용 프로토타입입니다.
- 실시간 대전은 서버가 공/점수 상태를 관리하는 간단한 구조입니다.
- 로그인, 관전자, 랭킹 저장, 부정행위 방지, 관리자 기능은 포함하지 않습니다.
