# 귀뚜라미 테니스 클럽

개인 연습(컴퓨터 상대)과 실시간 2인 대전을 지원하는 웹게임입니다.

## 포함 기능
- 로비(선수 선택 대시보드) → 경기 시작을 누르면 경기 화면으로 전환, 경기 후 '선수 다시 고르기'로 로비 복귀
- 개인 연습: 키보드/터치 조작, 컴퓨터 상대(쉬움·보통·어려움)
- 실제 테니스 단식 규칙: 실제 규격 세로 코트, 대각선 서브, 폴트·더블 폴트·레트, 원 바운드·발리, 아웃·네트, 15-30-40·듀스·어드밴티지, 게임·세트·타이브레이크
- 경기 방식: 짧은 세트(4게임) / 1세트(6게임) / 3세트 2선승
- 캐릭터 선택: 4명의 귀뚜라미 선수, 선수마다 다른 필살기
- 기 게이지: 공을 받아치면 +20%, 실점하면 +15%, 100%가 되면 필살기 사용 가능
- 실시간 대전: 방 만들기, 6자리 방 코드 공유, 2명 접속
- 열린 방 목록: 만든 방이 실시간 대전 로비의 '열린 방' 목록에 보여 누구나 눌러서 참가(비공개 방은 코드로만 참가)
- PC 및 모바일 브라우저 지원
- Node.js + Express + WebSocket

## 로컬 실행
1. Node.js 18 이상 설치: https://nodejs.org/
2. 압축을 푼 폴더에서 터미널/명령 프롬프트 실행
3. 아래 명령 실행

```bash
npm install
npm start
```

4. 브라우저에서 `http://localhost:3000` 접속

같은 와이파이의 다른 기기에서 접속하려면 호스트 PC의 내부 IP를 확인한 뒤 `http://호스트PC_IP:3000`으로 접속하세요. 방화벽에서 TCP 3000 포트를 허용해야 할 수 있습니다.

## 인터넷에 공개 배포하기 (Render 예시)
실시간 대전은 WebSocket 연결을 지원하는 서버에 배포해야 합니다. 정적 호스팅만으로는 실시간 대전이 동작하지 않습니다.

1. 이 프로젝트 폴더를 GitHub 저장소에 업로드합니다.
2. Render에서 **New + → Web Service**를 선택하고 GitHub 저장소를 연결합니다.
3. Runtime은 Node, Build Command는 `npm install`, Start Command는 `npm start`로 설정합니다.
4. 배포가 끝나면 Render가 제공하는 HTTPS 주소를 직원들에게 공유합니다.
5. 한 명은 **방 만들기**, 다른 직원은 같은 주소에서 **실시간 대전 → 방 코드 입력 → 참가**를 누릅니다.

**실시간 대전을 부드럽게 하려면 서버 지역이 중요합니다.** 한국에서 접속한다면 서비스를 만들 때 Region을 가장 가까운 곳(Render 기준 Singapore)으로 고르세요. 미국 지역 서버는 왕복 지연이 길어 상대 움직임이 늦게 보입니다. 경기 화면과 로비에 '연결 좋음/보통/느림(ms)'이 표시되니 참고하세요.

Render는 플랜/요금 및 무료 서비스 정책이 변경될 수 있습니다. 무료 인스턴스는 일정 시간 비활성 후 잠들 수 있어 첫 접속이 늦어질 수 있습니다. 실시간 대전은 두 브라우저가 같은 배포 서버에 접속해야 합니다.

## 🏆 대회 (모드 선택 화면의 '🏆 대회')
- 코트마다 대회가 하나씩: 🟦 귀뚜라미 오픈 · 🟧 귀랑스 오픈 · 🟩 귀블던(이상 정식 대회) · ❄️ 귀뚤 아이스 클래식 · 🚢 해적왕 컵 · 🌲 정글 서바이벌 리그 · ☀️ 주차장 그랑프리 · 🪨 클리프 마스터스(이상 이색 대회)
- 진행: 내 선수 + 컴퓨터 7명, 8명이 서로 한 번씩 붙는 **풀리그 7라운드**(짧은 세트 · 4게임) → **리그 1·2위 결승**(3세트 2선승) → 시상식(1~3위 시상대, 우승 소감)
- 내 경기는 직접 플레이(상대 컴퓨터 난이도는 대회 시작 때 선택). 다른 경기는 컴퓨터끼리 같은 경기 엔진으로 화면 없이 실제로 경기를 치러 결과를 냄(한 경기 약 0.1초)
- 순위: 승수 → 승자승(승수가 같은 선수끼리의 맞대결) → 세트 득실 → 게임 득실
- 결승에 못 오르면 결승전은 컴퓨터끼리 진행하고 결과만 봄. 경기 도중 나가면 기권패
- 📰 대회 소식: 반칙 아웃 콜, 낙석, 숨은 구덩이, 바나나 껍질, 이변(3라운드부터), 완봉승, 타이브레이크, 라이벌전 결과를 헤드라인으로 자동 작성
- 🔥 빅매치: 개시키 vs 바나킹(정의 vs 흑막), 개시키 vs 귀뚤냥이(견묘지간), 귀뚤냥이 vs 바나킹(악당 대결), 귀뚤냥이 vs 꺼꾸리(앙숙 신경전), 귀뚤냥이 vs 귀뚜라미 선수(천적전), 꺼꾸리 vs 귀뚜라미 선수(개구리 혀 주의보)
- 코트 궁합: 대회 시작 화면에 그 코트에서 강세·고전인 선수를 표시(컴퓨터끼리 코트마다 168경기씩 돌린 결과)
- 진행 상황과 트로피는 이 기기에 저장(계정 닉네임별, 게스트는 한곳에 모아 저장). 중간에 나가도 이어 하기 가능. 개인 연습처럼 서버 전적에는 넣지 않음
- 칭호: 정식 대회 3개 우승 → 🎾 귀뚤 그랜드슬램 · 8개 모두 우승 → 👑 코트의 지배자(경기 중 내 선수 라켓이 금빛으로 빛남)
- 전적 화면의 '🏆 트로피' 탭에서 대회별 최고 성적·우승 횟수·칭호 확인

## 채팅 (실시간 대전)
- 같은 방에 들어온 두 사람끼리 채팅. 로비(방 안)와 경기 화면 모두에서 사용
- 빠른 채팅 버튼: 좋은 경기 해요! / 나이스 샷! 👏 / ㅋㅋㅋㅋ / 아깝다~ / 한 판 더? / 잠깐만요! / GG
- PC 경기 중: Enter로 입력창, 보내면 다시 경기로(Esc는 취소). 휴대폰: 상단 💬 버튼(새 메시지는 빨간 점)
- 경기 중 메시지는 선수 머리 위 말풍선으로도 보임. 입장·퇴장 알림, 최근 30개 기록, 5초에 5개까지(도배 방지)

## 환경 디버프
- **게임마다 한 번쯤**(90%) 버프나 디버프 중 하나가 게임 중 아무 포인트 사이(0~3포인트 뒤)에 시작되어 **점수가 2번 날 때까지**(누가 점수를 내든) 유지. 연달아 같은 종류는 안 나옴
- 🌿 잡초: "아앗! 잡초가 자라났다!! 모두 뽑을 준비해!!" — 양쪽 코트에 잡초 덤불 3개씩. 공이 떨어지면 어디로 튈지 모르고, 밟으면 느려짐
- 🚨 비상벨: "비상구는 이쪽입니다. Here is emergency exit!" — 사이렌과 빨간 경광등, 비상구 표시. 모두 우왕좌왕해서 조작 방향이 수시로 틀어지고 가만히 있어도 움찔움찔 움직임
- 🌧️ 비: "아앗 하늘에서 비가 온다." — 천둥과 빗소리, 양쪽 코트에 웅덩이 3개씩. 공이 웅덩이에 떨어지면 첨벙 멈추거나 엉뚱한 방향으로 미끄러지고, 밟으면 느려짐
- 컴퓨터 선수도 똑같이 영향을 받습니다.

## 환경 버프
- 디버프와 반반 확률로 나옴(같은 쪽이 세 번 연속 나오지 않음). 버프와 디버프는 동시에 나오지 않음
- 🍃 맑은 공기: "숲속같이 맑은 공기가 들어온다!!" — 두 선수 모든 능력치 +1, 나뭇잎·반짝이가 날리는 연출
- ♨️ AI 코트 난방: "아니! 이거슨 방방 난방기술을 활용한 AI 코트 난방?!" — 몸이 풀려 선수 이동 속도 1.2배, 공(샷·서브) 약 15% 빨라짐, 따뜻한 주황빛 연출

## 아이템
- 포인트가 끝날 때마다 각 선수가 일정 확률로 무작위 아이템을 하나 얻습니다(최대 3개).
- 🐟 죽방멸치: 순간 튼튼해져 공(샷·서브)이 약 1.8배 빨라지고, 낮게 깔려 튄 뒤에도 속도가 유지되며, 묵직해서 상대가 받기 어려워짐
- 🥛 서울우유: 캐릭터가 커져서 공을 받을 수 있는 범위가 넓어짐
- ☕ 로빈 쿠폰: 공짜 커피로 집중력이 올라 정확도가 좋아지고, 스핀이 걸려 공이 휘어 들어가며 튄 뒤 더 뻗음
- 효과는 사용한 포인트가 끝나면(점수를 따거나 잃으면) 사라집니다. 같은 아이템은 한 포인트에 한 번만 효과가 있습니다.
- 사용: PC는 숫자 1·2·3(또는 아이템 칸 클릭), 휴대폰은 코트 왼쪽의 아이템 아이콘을 누름
- 컴퓨터도 아이템을 얻고 사용합니다.

## 소리
- 효과음: 로비 버튼을 누를 때 '뿅'(경기 시작·방 참가는 '뿅뿅'), 라켓 타격(기술별로 다른 소리), 바운드, 네트, 아웃·폴트 부저, 득점·실점 차임, 관중 환호, 게임·세트·우승 팡파르, 필살기·아이템·도발 소리, 귀뚜라미 울음
- 배경음(로비): 숲속 자연의 소리(산들바람, 나뭇잎 바스락, 시냇물, 찌르르 귀뚜라미, 새소리)로 시작해 8초 뒤 마림바 반주로 시작하는 경쾌한 음악이 이어짐. 음악이 나오면 자연 소리는 작게 깔림
- 배경음(경기): 음악은 1.5초 안에 사라지고, 자연 소리만 처음 몇 초 들리다가 서서히 사라져 경기에 집중할 수 있게 함
- 모든 소리는 브라우저에서 직접 만들어 내므로 별도 음원 파일이 없습니다(저작권 걱정 없음).
- 오른쪽 위 🔊 효과음 / 🌿 배경음 버튼으로 켜고 끔(설정은 기기에 저장). 휴대폰 경기 화면은 상단 🔊 버튼을 누를 때마다 모두 켬 → 배경음 끔 → 모두 끔
- 브라우저 정책상 화면을 한 번 누르거나 키를 누른 뒤부터 소리가 납니다. 아이폰은 무음 모드에서는 소리가 나지 않을 수 있습니다.

- PC는 T 키·도발 버튼, 휴대폰은 필살기 버튼 바로 아래 😜 버튼. **경기 중에도 사용 가능**
- 8가지 동작 중 하나가 무작위로 나오고 멘트도 함께 뜸: 엉덩이 흔들기, 더듬이 까딱, 승리의 댄스, 라켓 돌리기, 하품하기, 방방 점프, 메롱, 귀뚜라미 노래
- 상대 화면 직격: 도발당한 쪽 화면에 도발한 캐릭터가 크게 튀어나오며 멘트 컷인, 화면 흔들림, 코트에 😜 도장
- 관중 반응: 동작에 따라 야유("우~~") 또는 웃음("와하하"), 콤보 단계가 오를수록 커짐
- 도발 콤보: 2.5초 안에 다시 도발하면 2단계 → 3단계(캐릭터가 커지고 빛나며 멘트가 더 세짐)

- 경기 중(서브·랠리) 도발은 0.9초 동안 움직이거나 칠 수 없는 대가가 있음. 상대 화면 컷인도 경기 중에는 작고 짧게 떠서 공을 가리지 않음
- 컴퓨터도 포인트를 따면 가끔 도발하고, 내 도발에 가끔 맞도발함(랠리 중에는 안 함)

## 휴대폰
- 휴대폰·태블릿으로 접속하면 전용 경기 화면이 자동으로 뜹니다(세로 화면).
- 코트가 화면을 가득 채우고, 조작부는 코트 위에 반투명하게 겹쳐 보입니다.
- 왼손: 코트 왼쪽 아래를 누르면 그 자리에 조이스틱이 생겨 이동
- 오른손: 코트 오른쪽 아래 원을 누르면 타격(상황에 따라 서브·다음 서브·새 경기), 원 주위의 로브(위)·드롭(아래)·발리(왼쪽)·스매쉬(오른쪽) 버튼을 누르면 기술
- 필살기는 원 위쪽의 별도 버튼(기 100%일 때 주황색), 그 바로 아래에 도발 버튼
- 조이스틱을 기울인 채 치면 그 방향으로 코스 조절, 두 손가락 동시 터치 지원
- 브라우저 메뉴의 '홈 화면에 추가'로 설치하면 주소창 없이 전체 화면으로 열립니다(코트가 더 크게 보임).

## 휴대폰 화면
- 휴대폰 화면은 **창 폭이 아니라 기기 종류**로 정함: 손가락 터치가 주 입력인 기기(휴대폰·태블릿)는 모바일 화면, 마우스를 쓰는 PC는 창을 좁혀도 PC 화면(처음 열 때 한 번 판단)
- 머리글의 화면 모드 버튼(🖥️ 자동 → 🖥️ PC 화면 → 📱 모바일 화면)으로 직접 고를 수 있고, 고른 모드는 기억됨
- 입장·모드 선택·전적·로비 화면은 휴대폰 폭에 맞춰 한 줄 머리글(제목 + 🔊/🌿 아이콘 버튼), 손가락으로 누르기 쉬운 크기(42px 이상)의 버튼으로 바뀜
- 로비에서는 '경기 시작 / Ready' 버튼이 화면 아래에 항상 떠 있어 스크롤하지 않아도 누를 수 있음
- 입력칸은 16px 글씨라 아이폰에서 눌러도 화면이 확대되지 않음, 노치·홈 막대 영역을 피해서 배치

## 화면 흐름
1. 로딩 화면 → 2. 입장(로그인 또는 게스트) → 3. 모드 선택(개인 연습 / 실시간 대전) → 4. 로비 무대 → 5. 경기
- 로그인: 닉네임 + 숫자 비밀번호 4자리. 처음 쓰는 닉네임이면 새 계정이 만들어짐. 계정은 이 기기(브라우저)의 저장소에만 저장되며(`ct_accounts`), 고른 선수·코트와 전적(승패)이 함께 저장됨. "자동 로그인"을 켜 두면 다음부터 바로 모드 선택 화면으로 감
- 게스트: "게스트1234" 같은 이름으로 바로 시작, 기록은 저장되지 않음
- 로비 무대: 고른 코트가 무대와 페이지 배경이 되고, 가운데 선수가 반응함
  - 개인 연습: 쉬움 → 춤, 보통 → 의지 다지기, 어려움 → 두려워 떨기(흑막 원숭이 바나킹은 겁먹지 않고 화를 냄)
  - 실시간 대전: 상대를 기다리는 동안 라켓 돌리기, 상대가 들어오면 의지 다지기(개시키 vs 바나킹은 전용 멘트)
  - 코트를 바꾸면 한 번 반응: 빙판 휘청, 바다 뱃멀미, 숲속 두리번, 주차장 '아 뜨거!', 잔도 휘청, 클레이 흙 털기, 잔디 기지개, 하드 끄덕, 무작위 한 바퀴
- 추후 서버 계정으로 넓힐 때는 index.html의 '계정' 부분(loadAccs·saveAccs·doLogin)만 서버 요청으로 바꾸면 됨

## 서버 계정 (Neon 등 Postgres)
- Render 서비스의 Environment에 `DATABASE_URL`(Neon 연결 문자열)이 있으면 계정이 게임 서버 데이터베이스에 저장됩니다. 표(ct_users)는 서버가 처음 켜질 때 자동으로 만들어집니다.
- 선택: `SESSION_SECRET`에 아무도 모르는 긴 임의 문자열을 넣어 두면 로그인 토큰 서명에 쓰입니다(없으면 DATABASE_URL로 만든 값을 씀).
- 로그인: 닉네임(대소문자·앞뒤 공백 구분 없음) + 숫자 비밀번호 4~8자리. 비밀번호는 scrypt로 암호화해 저장하고 원문은 저장하지 않습니다.
- 같은 닉네임으로 5번 틀리면 1분, 같은 곳(IP)에서 20번 틀리면 10분 동안 로그인이 막힙니다.
- 저장되는 것: 닉네임, 고른 선수·코트, 전적(승패)과 경기 기록(ct_matches 표). **전적에는 사람과 한 실시간 대전만** 들어가고, 컴퓨터와 한 개인 연습은 기록하지 않습니다. 실시간 대전 결과는 서버가 직접 기록합니다.
- 이 기기에 저장돼 있던 같은 닉네임의 전적은, 서버 계정을 처음 만들 때 한 번 옮겨 옵니다.
- `DATABASE_URL`이 없거나 연결에 실패하면, 또는 index.html 파일을 그냥 열면 예전처럼 기기 저장 방식으로 동작합니다.
- 배포 후 Render 로그에 `계정 저장소: postgres 연결됨`이 보이면 정상입니다.
- API: GET /api/status, POST /api/login, GET /api/me, POST /api/prefs, POST /api/import, GET /api/history(내 최근 실시간 대전 30경기), GET /api/top(전적 상위 10명)

## 전적 화면 (모드 선택 화면의 '📊 전적 보기')
- 요약: 승·패, 승률, 경기 수, 연승/연패, 자주 쓰는 선수
- 최근 경기: 날짜·결과·상대(선수)·코트·경기 방식·세트 스코어 / 상대별: 상대마다 몇 승 몇 패 / 랭킹 TOP 10(서버 계정일 때)
- 게스트는 기록되지 않음. 이 기기 계정은 이 기기에서 한 실시간 대전만 보여 줌

## 실시간 대전 시작: Ready

- 꺼꾸리 특성 '점프 이동': 0.22초 점프 + 0.05초 착지를 반복하며 이동(뛰는 동안엔 방향을 못 바꿈, 대신 평균 속도 1.13배) / '긴 혀': 0.5m 더 높은 공까지 칠 수 있음 / '비가 좋아': 비 디버프 중 1.1배, 물웅덩이(비·파도)에선 느려지지 않고 1.15배 / '청개구리 심보': 상대가 도발하면 내 기 +10%, 맞도발(반사) 인정 시간 2.5초. 멘트는 반대로 함("이겼다 개굴! (졌다)")
- 파워: 공 속도 · 스피드: 이동 속도 · 컨트롤: 정확도 · 스핀: 평소 샷이 휘는 폭(스핀 5 기준 약 0.7m)과 튄 뒤 뻗는 정도(1이면 완전 직진) · 리치: 공을 받을 수 있는 범위 · 서브: 서브 속도와 정확도
- 능력치 합계는 모두 19로 같고, 컴퓨터끼리 경기시켜 득점률이 비슷하게(약 46~54%) 나오도록 맞췄습니다. 대회 추가와 함께 파이어 뚜리(불꽃샷 0.45→0.62초, 받는 범위 감소 15%→3%)와 꺼꾸리(이동 1.08→1.13배)를 조정해, 8명 모두 득점률 약 47~54% 안에 들어옴. 다만 짧은 세트에선 득점률 차이가 경기 승률로 크게 벌어져 개시키·바나킹·파이어 뚜리가 강한 편

## 조작
- 이동: 방향키
- 기본 타격: 스페이스바 · 기술(왼손 QWER): Q 스매쉬 / W 로브 / E 필살기 · A 발리 / S 슬라이스 / D 드롭 · Ctrl 대시
- 서브: Space (←→로 위치 조정, 키를 누른 채 서브하면 코스 조절)
- 다음 서브: 포인트가 끝난 뒤 Space · 새 경기: 경기 종료 후 Space (한글 입력 상태에서도 동작)
- 칠 때 ←→를 누르고 있으면 그쪽으로, 네트 쪽 키는 깊게·반대쪽 키는 짧게
- 모바일: 화면 방향키와 공 치기·기술 버튼

## 파일 구성
- `public/engine.js`: 경기 규칙·공 물리·컴퓨터 선수. 개인전(브라우저)과 실시간 대전(서버)이 같은 파일을 사용합니다.
- `public/index.html`: 화면과 조작
- `server.js`: 실시간 대전 서버

## 실시간 대전 지연 줄이기(적용됨)
- 내 선수는 내 화면에서 바로 움직이고, 서버는 속도·코트 범위만 검사합니다.
- 상대 선수와 공은 서버 상태를 0.1초 모아 두었다가 그 사이를 이어서 그려 끊김을 줄입니다.
- 서버가 보내는 데이터를 화면에 필요한 값만 골라 약 4.9KB → 0.4KB로 줄였습니다.
- 칠 때는 내 화면에 보이던 조금 전 공 위치까지 인정해, 지연 때문에 헛스윙 되는 일을 줄였습니다.

## 참고
- 현재 버전은 사내 친선 게임용 프로토타입입니다.
- 실시간 대전은 서버가 공/점수 상태를 관리하는 간단한 구조입니다.
- 실제 경기의 코트 체인지(홀수 게임마다)는 점수 안내만 하고, 화면은 내 선수가 항상 아래에 보이도록 유지합니다.
- 로그인, 관전자, 랭킹 저장, 부정행위 방지, 관리자 기능은 포함하지 않습니다.
